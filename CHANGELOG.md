# Changelog

All notable changes to PDelay are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0] - 2025-01-15

### Added
- Initial public release
- Command-line delay/sleep utility for scripts and batch files
- Flexible time format (hours, minutes, seconds, milliseconds, combined values)
- Quiet mode without progress display
